
# AeroTech Avionics
## Sistema de Diseño - Versión 1.0

### 1. Identidad visual
AeroTech Avionics es una empresa ficticia de
soluciones aeroespaciales y de defensa.

Estilo seleccionado: Militar corporativo.

El diseño debe transmitir:
- Profesionalismo
- Tecnología
- Seguridad
- Innovación
- Precisión

### 2. Paleta de colores
- Primario: #14263D
- Secundario: #243B53
- Acento: #38BDF8
- Fondo: #F4F6F9
- Texto: #1E293B

### 3. Tecnologías
- React
- JavaScript
- Bootstrap 5
- CSS personalizado

### 4. Reglas CSS
- Usar las variables globales de colores.
- Evitar colores arbitrarios en componentes.
- Priorizar las clases de Bootstrap.
- Mantener un diseño responsivo.
- Evitar estilos inline innecesarios.
- Utilizar archivos CSS para estilos personalizados.

### 5. Componentes
- Un componente debe tener una responsabilidad.
- Los componentes React usarán PascalCase.
- Ejemplo: Navbar.jsx, Dashboard.jsx.
- Los componentes compartidos estarán en
  src/components/.

### 6. Diseño responsivo
- Móvil: menos de 768px.
- Tablet: desde 768px.
- Escritorio: desde 992px.

Usar los breakpoints y utilidades de Bootstrap.

### 7. Convenciones visuales
- Botones primarios en azul corporativo.
- Formularios con etiquetas visibles.
- Tarjetas con bordes suaves.
- Espaciado uniforme.
- Navegación consistente entre páginas.

### 8. Trabajo colaborativo
Los tres integrantes deben respetar
este documento antes de desarrollar
nuevas vistas o componentes.
